# FieldNotes

FieldNotes is the companion application's canonical, runnable state. It is a
private research notebook that remains useful before any model-backed feature
is enabled.

The first reader-facing increment supports:

- an honest loading, empty, error, loaded, and partial-success state model;
- a list of sample field notes with stable identity;
- typed navigation to note details;
- an item-driven capture sheet;
- whitespace validation and asynchronous saving;
- an actor-isolated in-memory store;
- self-contained previews, unit tests, and a UI smoke test.

Open `FieldNotes.xcodeproj` in Xcode or run the scripts one directory above.
