# Chapter 29 Evaluation Lab

This package turns FieldNotes product promises into deterministic graders. Its
10-case golden dataset stores inputs, fixtures, and required properties rather
than blessed output strings; 6 cases are the permanent adversarial regression
tier inherited from the security audit.

The 5-record human review fixture measures pass/fail agreement on a written
usefulness criterion. The model-judge candidate is refused unless it reaches
90% agreement with the first human reviewer.
