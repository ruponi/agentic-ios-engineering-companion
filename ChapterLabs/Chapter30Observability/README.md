# Chapter 30 Observability Lab

This package stitches content-free device, backend, model, tool, and change
events by one correlation UUID. It observes the canonical loop against its
existing four budgets, measures a deterministic two-chunk responsiveness probe,
and proves that the feature flag's OFF route returns the existing deterministic
packing brief.

The trace deliberately has no fields for note text, prompt text, tool bodies,
user identity, credentials, or a generated request summary.
